# UI and Feature Refinement Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Clean up redundant UI elements and remove irrelevant features to streamline the "SUTU" community platform.

**Architecture:** Next.js App Router, Tailwind CSS, Framer Motion.

**Tech Stack:** React, Tailwind CSS, Lucide React, Framer Motion.

---

### Analysis: Irrelevant/Missing Elements

**Irrelevant/Redundant:**
1. **Template.tsx:** Seringkali redundant jika layout sudah cukup. Akan dicek apakah memberikan value (misal: exit animations) atau hanya boilerplate.
2. **Featured Spotlight (Main Page):** Jika data komunitas masih sedikit, spotlight bisa terasa kosong.
3. **Trending Page vs Main Page:** Jika platform baru, "Trending" dan "Discover" (Main) sering menampilkan data yang sama. Perlu merger atau diferensiasi yang kuat.

**Missing/Kurang:**
1. **Empty States:** Belum ada penanganan jika filter tidak menemukan hasil.
2. **Loading Skeletons:** Penting untuk UX Next.js.
3. **Interactive Feedback:** Button hover states dan active states di Navigation.
